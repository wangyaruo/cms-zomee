## 第一阶段交付边界

第一阶段目标是一个真实可登录、可持久化的 CMS 基础，不是已经完成原站替换。只有“原站数据导入、快照适配、构建预览、生产部署、回滚”全部完成后，运营在后台的发布才会改变正式网站。
